حساباتي 1.1.4

إصلاحات ومميزات النسخة:
- إصلاح مشكلة الشاشة البيضاء/الفارغة عند تشغيل البرنامج عبر تقوية تحميل البيانات والحالة الأولية.
- زر «تفعيل البرنامج» أثناء الفترة التجريبية.
- التفعيل الآن أو بعد 14 يوم أو من تاريخ محدد عبر مولّد التفعيل.
- إخفاء QR/باركود الفاتورة من طباعة فواتير البيع.
- طباعة فواتير 80mm مباشرة للطابعة عند استخدام زر الطباعة.
- مولّد التفعيل يحتوي على «نسخ الكود» بطريقة ثابتة عبر Electron.
- المفتاح الخاص private-key.pem لا يُرسل للعملاء.
